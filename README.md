# GREEN-API Chat

Небольшое веб-приложение для отправки и получения текстовых сообщений через GREEN-API

## Возможности

- Вход по ID и токену GREEN-API
- Сохранение данных входа в браузере
- Создание чатов по номеру телефона
- Отправка текстовых сообщений
- Получение входящих сообщений через long polling

## Запуск

Нужен Node.js 20 или новее

```bash
npm install
npm run dev
```

После запуска откройте адрес, который покажет Vite

## Проверки

```bash
npm run biome:check
npm run lint
npm test
npm run typecheck
npm run build
```

## Как пользоваться

1. Создайте аккаунт GREEN-API и получите ID и токен
2. Откройте приложение и введите эти данные
3. Введите номер получателя в международном формате, например `79991234567`
4. Откройте чат и отправьте сообщение

Данные входа хранятся только в `localStorage` вашего браузера

## Структура

Проект использует Feature-Sliced Design

```text
src/
  app/       # Провайдеры и глобальные стили
  pages/     # Страницы
  widgets/   # Крупные части интерфейса
  features/  # Пользовательские действия
  entities/  # Чаты, сообщения и сессия
  shared/    # API, утилиты и базовый UI
```
